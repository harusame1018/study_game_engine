ゲームと教育システムをむすびつけると面白のでは？

npm run devで実行できます

package.jsonにほかのコマンドもかいてあります

使用技術はpixijsとviteです

## 使用方法
/createにアクセスしてもらうと、問題作成ページになります。（ならない場合は再読み込みをしてください）
そこで問題を入力し、「json生成」を押すとリンクが生成されるので、そこにアクセスしてもらうとゲームをプレイできます。
また、そのリンクを配布することでほかの人に問題をプレイしてもらうことが可能になります。

## どんな問題が作れるのか
三択問題しか作れません😭
